INTERPRETATION
================================

1. Retrieval recall improved substantially.
   Context recall increased from 0.50 to 1.00, indicating that the
   relevant information required for both evaluated questions was
   successfully retrieved in the current run.

2. Retrieval precision improved but remains imperfect.
   Context precision increased from 0.50 to 0.6417. This suggests that
   relevant evidence is being retrieved, but the retrieved context still
   contains additional or less relevant chunks.

3. Faithfulness improved.
   Faithfulness increased from 0.7083 to 0.8333, with the religion
   question achieving a score of 1.0.

4. Answer relevancy remains a weakness.
   Answer relevancy decreased slightly from 0.6810 to 0.6409.
   This suggests that improvements in retrieval recall have not
   automatically translated into more focused generated answers.

5. Retrieval diagnostics indicate that BM25 has a strong influence
   on the current ranking. The dense-retrieval contribution should
   be investigated further before claiming that RRF consistently
   improves ranking quality.

6. The current experiment therefore provides a baseline for studying
   hybrid retrieval quality rather than a final optimized retrieval
   system.


CURRENT LIMITATIONS
================================

- Evaluation set currently contains only two questions.
- RAGAS scores should therefore be treated as an initial diagnostic
  rather than a statistically robust benchmark.
- Dense retrieval contribution requires further diagnostic validation.
- Generic chunking is currently used.
- Structure-aware document segmentation has not yet been evaluated.


NEXT PLANNED IMPROVEMENT
================================

Structure-aware document segmentation is in progress.

The planned improvement is to compare generic chunking against
structure-aware segmentation while keeping the retrieval architecture
(BM25 + dense retrieval + RRF) as controlled as possible.

The purpose is to determine whether preserving legal document
structure improves retrieval precision and contextual relevance.
